# QueryAI – AI-Powered Natural Language to Pandas Query Generator

QueryAI is an AI-powered web application that converts natural language questions into executable Python Pandas code and generates answers from uploaded datasets.

It allows users to interact with their data using simple English instead of writing complex Pandas queries manually. The application uses LangChain and Groq LLM to understand user questions, generate Python code, and display the results through an interactive Streamlit interface.

## Features

- **Multiple Dataset Formats:** Upload datasets in CSV, Excel, TSV, Parquet, and JSON formats.
- **Natural Language Queries:** Ask questions about your dataset using simple English.
- **AI-Powered Code Generation:** Generate Python Pandas code using Groq LLM.
- **Code Display:** View the Pandas code generated by the AI.
- **Automated Answer Generation:** Execute the generated code and display the results.
- **Interactive Interface:** Simple and user-friendly Streamlit web application.
- **Error Handling:** Display errors when a dataset cannot be processed or a query fails.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/harshadapadwal0305/QueryAI.git
```

### 2. Navigate to the Project Folder

```bash
cd QueryAI
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Groq API Key

Create a file named `.env` in the project folder and add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key
```

Replace `your_groq_api_key` with your actual API key.

**Note:** Never upload your `.env` file or API key to GitHub.

### 5. Run the Application

```bash
streamlit run app_qg.py
```

The application will open in your default web browser.

## How It Works

1. **Upload Dataset:** The user uploads a dataset in a supported file format.
2. **Enter Question:** The user enters a question in simple natural language.
3. **AI Processing:** The question and dataset information are sent to the Groq language model through LangChain.
4. **Code Generation:** The AI generates the required Python Pandas code.
5. **Code Execution:** The application executes the generated code on the uploaded dataset.
6. **Display Result:** The generated code and final answer are displayed in the Streamlit interface.

## Important Note

QueryAI is developed as a learning and practice project. It executes AI-generated Python code locally using `exec()`. The current code checks for some potentially unsafe patterns, but these checks do not provide a secure sandbox. Therefore, the application should only be used with trusted inputs and should not be exposed to untrusted users without proper security improvements.
